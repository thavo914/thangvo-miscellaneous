# 🏃‍♂️ Marathon Training Plan

A comprehensive 26-week Full Marathon training plan following the MAF (Maximum Aerobic Function) method, designed to help you achieve your marathon goals safely and effectively.

## 📋 Plan Overview

- **Duration**: 26 weeks
- **Runs per week**: 5 runs + 2 rest days
- **Target**: Sub-4:30 marathon completion
- **Methodology**: MAF-based training with progressive overload

- **[Nutrition & Hydration](nutrition-hydration.md)** - Fueling strategies for training and race day

## 🗓️ Weekly Schedule

| Day | Workout Type | Description |
|-----|--------------|-------------|
| **Monday** | Rest | Complete rest or light active recovery |
| **Tuesday** | High Intensity | Intervals (odd weeks) or Tempo (even weeks) |
| **Wednesday** | Easy Run | MAF pace, 8 km |
| **Thursday** | Medium-Long Run | MAF pace, progressive distance |
| **Friday** | Light Rest | Mobility work and foam rolling |
| **Saturday** | Easy Run | MAF pace, 8 km |
| **Sunday** | Long Run | MAF pace, progressive distance |

## 🎯 Key Training Principles

- **MAF Pace (6:50/km)**: Builds aerobic base and fat-burning efficiency
- **Progressive Overload**: Weekly distance increases for gradual adaptation
- **Recovery Focus**: Strategic rest days and easy runs
- **Specificity**: Marathon-pace practice in long runs
- **Taper Strategy**: 2-week taper for optimal race performance

## 🚀 Getting Started

1. **Assess Your Current Fitness**: Ensure you can comfortably run 8-10 km
2. **Set Your Target**: Determine your goal marathon time
3. **Follow the Schedule**: Start with Week 1 and progress systematically
4. **Listen to Your Body**: Adjust volume if needed based on recovery
5. **Practice Nutrition**: Test fueling strategies during long runs

## 📊 Training Metrics

- **Weekly Volume**: Progressive increase from ~45 km to ~80 km
- **Long Run Distance**: Builds from 14 km to 36 km
- **Speed Work**: Intervals and tempo runs for performance gains
- **Recovery**: MAF-pace runs for aerobic development

## ⚠️ Important Notes

- **Always warm up** before high-intensity workouts
- **Stay hydrated** during runs longer than 60 minutes
- **Monitor fatigue** and adjust training as needed
- **Practice race nutrition** during long runs
- **Include strength work** for injury prevention
