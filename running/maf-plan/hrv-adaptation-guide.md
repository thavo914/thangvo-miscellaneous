```
Wake up → Take HRV reading (Garmin HRV Status or HRV4Training)
         ↓
         
Is HRV < 45ms  OR  Garmin shows "Unbalanced"?
├─ YES → 🔴 RED: Replace ANY quality session with easy Zone 2 run
│           • Skip Finish Strong entirely
│           • If today is Tuesday: easy Zone 2, no tempo/intervals
│           • If today is a rest day: stay rest
│           • Priority: SLEEP + RECOVERY
│
└─ NO → Is HRV 45–49ms  OR  Garmin shows "Low"?
        ├─ YES → 🟡 YELLOW: Reduced intensity
        │           • Tuesday: easy tempo only, RPE ≤ 6 max
        │           • No Finish Strong segments
        │           • Stop if HR climbs or effort feels too hard
        │
        └─ NO → Is HRV ≥ 50ms  AND  Garmin "Balanced" for 2+ days?
                ├─ YES → 🟢 GREEN: Proceed as planned
                │           • Tuesday: full quality session as written
                │           • Finish Strong eligible on MLR and LR
                │           • Follow all session details
                │
                └─ Is HRV ≥ 55ms  AND  Garmin "Balanced" for 3+ days?
                            └─ YES → 🟢+ BONUS: Add optional volume
                                        • Long run: may add 5–10% (e.g., 20→22 km)
                                        • Keep within 10% weekly cap
                                        • Finish Strong eligible
```

## 📋 Finish Strong Eligibility Checklist

Before starting a Finish Strong segment on **Friday MLR** or **Sunday LR**, verify ALL of these:

```
[ ] Morning HRV ≥ 50ms
[ ] Garmin shows "Balanced" for 2 or more consecutive days
[ ] Today is NOT the day after a Finish Strong segment (no back-to-back)
[ ] This is NOT a recovery week (Weeks 4, 8, 12)

If Tuesday was a FULL quality session this week:
    → Cap Finish Strong at 1 km max (not 2 km)

Phase restrictions:
    → Base (Wks 1–4): MRP only, 1 km max
    → Build (Wks 5–10): MRP or Tempo, 1–2 km
    → Peak (Wks 11–14): MRP or Tempo, 1–2 km (but cap at 1 km if Tuesday was full quality)
    → Taper (Wks 15–16): MRP only, 1 km max

All conditions met? → Execute Finish Strong
Any condition failed? → Pure MAF run, no Finish Strong
```

## 🔴 Red Flag Protocol — When to Back Down Immediately

Stop the session or reduce intensity RIGHT AWAY if:

| Signal | Action |
|--------|--------|
| HR > 147 bpm on an "easy" run | Walk until HR drops to 140, then resume slow jog |
| RPE jumps from 5 to 8 without pace change | This is cardiac stress — back off immediately |
| Breathing becomes labored at "easy" effort | Stop, walk, reassess |
| Legs feel heavy AND HR is elevated | End session early — this is accumulated fatigue |
| Nausea or dizziness during run | Stop immediately, sit, hydrate |

## 📈 HRV Tracking Tips

**When to measure HRV:**
- Every morning immediately upon waking, before standing up
- Lie still for 2 minutes, then measure
- Use consistent timing (same time each day ±15 min)

**What "normal" looks like for you (HRV 40–49ms range):**
- Your baseline average is ~40–49ms
- "Good" for you = above your personal 7-day average
- "Low" for you = more than 8–10ms below your 7-day average

**HRV trends matter more than single readings:**
- One low reading after a hard session = normal, proceed cautiously
- HRV declining for 3+ consecutive days = systemic fatigue → insert extra recovery
- HRV rising during a build week = excellent response to training

**Your HRV Green Light targets:**
| Phase | Target HRV for Full Quality Tuesday |
|-------|-------------------------------------|
| Base (Wks 1–4) | ≥ 48ms (no quality sessions, just monitoring) |
| Build (Wks 5–10) | ≥ 50ms |
| Peak (Wks 11–14) | ≥ 50ms, ideally 52ms+ |
| Taper (Wks 15–16) | Monitor for upward trend; target 55ms+ by race morning |

## 💤 Recovery Levers (Pull These If HRV Is Stuck Low)

When HRV stays below 45ms for 2+ consecutive days, in priority order:

1. **Sleep** — Add 30–60 min. Go to bed earlier. No screens after 9 PM.
2. **Nutrition** — Increase carbs (aerobic training depletes glycogen). Eat within 45 min post-run.
3. **Stress reduction** — Work, social, and life stress affect HRV just as much as running.
4. **Reduce non-running load** — Cut standing time, walking distance, and any optional activity.
5. **Reduce training** — If none of the above helps after 48h, shorten or skip planned session.
6. **Magnesium Glycinate** — 300–400mg before bed if not already doing this. Directly supports HRV.

## 🗓️ Weekly HRV Check Rhythm

| Day | HRV Action |
|-----|-----------|
| **Monday** | Measure: baseline after rest. Sets week's starting point. |
| **Tuesday** | Measure: gates quality session decision (see table above) |
| **Wednesday** | Measure: check Tuesday's recovery impact |
| **Thursday** | Rest day — measure to track midweek trend |
| **Friday** | Measure: gates Finish Strong eligibility on MLR |
| **Saturday** | Rest day — optional measure |
| **Sunday** | Measure: gates Finish Strong eligibility on LR |

> **Key rule**: HRV drops after hard sessions (Tuesday) are expected. What matters is the recovery by Wednesday/Thursday. If you're not recovering by Thursday, next Tuesday needs to be easier.
