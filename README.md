# ThangVo Miscellaneous

A comprehensive repository containing various learning materials and projects, primarily focused on English language development for data engineering professionals.

## 🎯 Project Overview

This repository serves as a centralized hub for multiple learning initiatives:

- **English Language Development** - Structured English learning program for B1→C1 level speakers
- **Data Engineering Topics** - Professional vocabulary and communication skills
- **Running Resources** - Additional learning materials and resources

## 🚀 Getting Started

### For English Learning (Primary Focus)

1. **Start with the English Program**: Navigate to `english/README.md` for the complete guide
2. **Choose Your Week**: Begin with `english/weeks/week-01/` and progress sequentially
3. **Follow the Daily Menu**: Use the structured 30/60/90-minute practice sessions
4. **Track Progress**: Maintain logs and recordings as outlined in the program

### Quick Start for English Learning

```bash
cd english
# Read the main guide
cat README.md

cd weeks/week-01
```

## 🎯 Learning Methodology

### **Speaking-First Approach**
- 60-70% of time spent on live speaking practice
- Role-play scenarios with AI or partners
- Real-time feedback and correction

### **Vocabulary System**
- Topic-based vocabulary building
- Professional and everyday language
- Structured 5-part vocabulary format
- Spaced repetition integration

### **Progress Tracking**

## 📈 Success Metrics

### **Weekly Goals**
- **Fluency**: 2-3 minute talks at 140-170 WPM
- **Vocabulary**: 5+ target chunks used naturally
- **Complexity**: ≥3 complex sentences per prepared talk
- **Clarity**: Speech-to-text transcript ~90% accurate
- **Consistency**: 5+ days per week

### **Progress Tracking**
- Daily logs with errors, fixes, and goals
- Weekly vocabulary and concept mastery
- Monthly fluency and complexity assessments
- Quarterly professional communication reviews
