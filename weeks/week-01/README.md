# Week 01: Data Engineering Fundamentals & Project Kickoff

## Overview
This week focuses on fundamental data engineering concepts and kicking off the SAS to MSSQL migration project.

## Topics Covered

### Data Engineering Fundamentals
- Data ingestion and processing pipelines
- Bronze, Silver, Gold data architecture
- Data quality and testing
- Schema management and data contracts

### Project Management
- Project status updates and stakeholder communication
- Meeting management and progress reporting
- Risk identification and mitigation

## Learning Materials

### Prompts
- **Meeting Status Update**: Practice giving project updates to stakeholders
- **Role Play**: Simulate various workplace scenarios

### Vocabularies
- **bottleneck**: Understanding system constraints
- **bronze-silver-gold**: Data architecture layers
- **data-contract**: Data quality agreements
- **downstream-tables**: Impact analysis
- **end-to-end**: Complete process understanding
- **from-ingestion-to-consumption**: Data flow
- **late-arriving-data**: Handling data delays
- **optimize-for-x-at-the-expense-of-y**: Trade-off analysis
- **schema-registry**: Data structure management
- **semantic-layer**: Business logic abstraction
- **watermark**: Data freshness indicators

## Practice Focus
- Clear, concise communication in B1 level English
- Project status reporting
- Technical concept explanation
- Stakeholder management

## Weekly Goals
- Master fundamental data engineering vocabulary
- Practice project status updates
- Develop confidence in technical discussions
- Build stakeholder communication skills
