# Week 01 · Day 1

Use this folder to do and save all Day 1 work for easy review later.

## What to do (90 minutes)

- Warm-up (10): 4–3–2 drill on pipeline; 1-min summary
- Input (15): read `input/model-text.md`; note 8–12 key sentences
- Shadowing (15): slow → normal → fast on those sentences
- Vocabularies (10): add 5–8 items in `vocabularies/` (one file per item using the format below)
- Speaking (25): 2–3 min PREP talk + repeat; 8–10 min Q&A using `prompts/role-play.md`
- Pronunciation (10): drill 3 lines focusing on stress and linking
- Log (5): fill the template below and save the file

## Files in this folder

- Input: `input/model-text.md`
- Role-play prompt: `prompts/role-play.md`
- Vocabularies: markdown files in `vocabularies/`
- Recordings: save audio files in `recordings/`
