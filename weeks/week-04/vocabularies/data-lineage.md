# Data Lineage

## Definition
The complete path that data takes from source systems through transformations to final consumption, showing how data flows and transforms across the pipeline.

## Example Sentences
- "dbt automatically generates data lineage diagrams showing how our models are connected."
- "Understanding data lineage helps us trace issues back to their source."
- "The data lineage documentation shows the complete journey of our customer data."

## Related Terms
- **Data flow**: Movement of data through systems
- **Transformation**: Process of changing data format or structure
- **Source system**: Original location of data
- **Downstream**: Systems that consume transformed data

## Usage Context
- Explaining data architecture to stakeholders
- Troubleshooting data issues
- Planning data governance initiatives
- Compliance and audit discussions
