# Materialization

## Definition
The strategy for persisting dbt models in the warehouse (table, view, incremental, ephemeral).

## Example Sentences
- "We materialize this model as a table since it's queried frequently by multiple teams."
- "The choice of materialization strategy depends on how often the data changes and how it's accessed."
- "Incremental materialization can significantly improve performance for large datasets."

## Related Terms
- **Table**: Persistent storage that stores all data
- **View**: Virtual table that queries underlying data
- **Incremental**: Model that processes only new/changed records
- **Ephemeral**: Temporary model that exists only during execution

## Usage Context
- Discussing performance optimization strategies
- Explaining storage trade-offs to stakeholders
- Planning data architecture decisions
- Code review discussions
