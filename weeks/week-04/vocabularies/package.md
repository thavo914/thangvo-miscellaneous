# Package

## Definition
A collection of dbt models, macros, and tests that can be shared and reused across projects to avoid duplication and maintain consistency.

## Example Sentences
- "The dbt_utils package provides helpful macros for common data transformation tasks."
- "We created an internal package for our company's standard business logic."
- "Using packages helps us maintain consistency across different dbt projects."

## Related Terms
- **Macro**: Reusable Jinja code within packages
- **Reusability**: Ability to use components across projects
- **Consistency**: Maintaining uniform patterns and standards
- **Collaboration**: Sharing code and best practices

## Usage Context
- Explaining code organization strategies
- Discussing development best practices
- Planning project architecture
- Team collaboration discussions
