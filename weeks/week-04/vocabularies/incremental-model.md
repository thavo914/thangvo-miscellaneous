# Incremental Model

## Definition
A model that only processes new or changed records since the last run, improving performance and reducing processing time.

## Example Sentences
- "Using incremental models reduced our processing time from 2 hours to 15 minutes."
- "We converted our daily aggregation model to incremental to handle the growing data volume."
- "Incremental models are perfect for slowly changing dimension tables."

## Related Terms
- **Full refresh**: Processing all data every time
- **Change data capture**: Identifying what data has changed
- **Performance optimization**: Improving speed and efficiency
- **Processing time**: Time required to complete data transformation

## Usage Context
- Explaining performance improvements to stakeholders
- Discussing optimization strategies with the team
- Planning data pipeline architecture
- Cost-benefit analysis discussions
