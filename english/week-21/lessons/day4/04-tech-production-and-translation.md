### 1. Model Translation 1
> *"The tracks **are being replaced between Wilmslow and Levenshulme** stations, so passengers will need to board a rail replacement bus."*
* **Linguistic Breakdown**: Dùng bị động tiếp diễn `are being replaced`. Sử dụng cụm giới từ ngắn gọn `between Wilmslow and Levenshulme` thay vì diễn giải rườm rà *"starting at... and ending at..."*. Dùng từ chuẩn ngành đường sắt `tracks` hoặc `railway line`.

### 2. Model Translation 2
> *"The secondary storage server **keeps making a beeping sound**, so the technician **is currently replacing** the failed hard drive **with** a new NVMe SSD (hoặc: ... the failed hard drive **is currently being replaced with** a new NVMe SSD)."*
* **Linguistic Breakdown**: Cấu trúc lặp lỗi `keeps making a beeping sound`. Dùng thể bị động tiếp diễn `is being replaced with` để chỉ hành động đang diễn ra tại chỗ.

### 3. Model Translation 3
> *"**One of the main reasons** our team decided to upgrade to this Kafka cluster **was because of the automated schema registry that was included**."*
* **Linguistic Breakdown**: Cấu trúc giải trình kỹ thuật `One of the reasons... was because of [X] that was included`.

## 🔍 Drill 3: Spot the Mistake (Tech Error Correction)

Identify and correct the operational or grammatical error in each sentence:

1. *The rail line is replacing right now between the two stations.*  
   → **Correction**: __________________________________________________
2. *As soon as the cluster starts up, I will hook up with the analytics database.*  
   → **Correction**: __________________________________________________
3. *Our replica node keeps make a high-pitched buzzing sound whenever memory usage spikes.*  
   → **Correction**: __________________________________________________

<details>
<summary>💡 Click to View Explanations & Corrections</summary>

1. **Incorrect**: *is replacing*  
   ✅ **Correct**: *The railway line / tracks **are being replaced** right now between the two stations.*  
   *Reason*: Lỗi thiếu bị động. Đường ray không tự thay thế chính nó được; bắt buộc phải dùng thể bị động `is/are being replaced`.
2. **Incorrect**: *hook up with the analytics database*  
   ✅ **Correct**: *As soon as the cluster starts up, I will **hook the service up to** the analytics database (hoặc: **hook it up to** the database).*  
   *Reason*: `hook up with` mang nghĩa lãng mạn/hẹn hò hoặc kết nối nhờ vả người khác. Để kết nối kỹ thuật giữa 2 hệ thống, dùng `hook [A] up to [B]`.
3. **Incorrect**: *keeps make*  
   ✅ **Correct**: *Our replica node **keeps making** a high-pitched buzzing sound whenever memory usage spikes.*  
   *Reason*: Sau `keep`, động từ bắt buộc phải chia ở dạng V-ing (`making`).
</details>
