## Phase 2 — Dictation Verification (25 min)
> Open your Day 1 draft. Compare it line-by-line with the annotated transcript.

**Error Classification Table** — Record 3 meaningful errors:

| # | Your Word / Gap | Actual Word | Error Type | Why You Missed It |
| :--- | :--- | :--- | :--- | :--- |
| 1 | | | Spelling / Mishear / Gap / Wrong word | |
| 2 | | | Spelling / Mishear / Gap / Wrong word | |
| 3 | | | Spelling / Mishear / Gap / Wrong word | |

**Error Types:**
- **Spelling** — You heard it correctly but wrote it wrong.
- **Mishear** — You heard a different word (e.g., "coercion" → "concern").
- **Gap** — You wrote nothing; the sound was lost entirely.
- **Wrong word** — You heard something but it was a completely different word.

## Phase 3 — Phonetic Drill (15 min)
> Drill each phrase **x5 out loud**, matching the stress, rhythm, and linking sounds shown in the annotated transcript.

| # | Phrase | Notes |
| :--- | :--- | :--- |
| 1 | "decisions are made by all employees equally" | Stress: **de**-ci-sions, **all**, **e**-qual-ly |
| 2 | "they must keep their commitments" | Stress: **must** keep, **com**-mit-ments |
| 3 | "be held accountable by anyone" | Linking: held_ac-**count**-able |
| 4 | "take full advantage of this environment" | Stress: **full** ad-**van**-tage, en-**vi**-ron-ment |

**Drill method:**
1. Listen to the phrase once in the episode.
2. Repeat x5 — speak slightly **faster** than feels comfortable.
3. Record yourself on rep 5. Compare to the original.
