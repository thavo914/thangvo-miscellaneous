## 📑 2. Target Collocations & Vocabulary Matrix

### Topic 1: Logistics Coordination & Customer Exceptions (Days 1–3)
| Collocation / Expression | POS | Vietnamese Meaning | Natural Workplace Context |
| :--- | :--- | :--- | :--- |
| `expecting a delivery` | Phrase | đang chờ nhận hàng / bưu kiện | Inquiring about incoming courier or hardware without using "expect for" |
| `under [Name]` | Preposition | đứng tên / đăng ký dưới tên | Verifying account or parcel identity: *"What name was the order placed under?"* |
| `reference number` | Noun Phrase | mã tham chiếu / mã tra cứu | Professional identifier (Ref #) instead of Vietlish "order code" |
| `should be back by` | Modal Pattern | dự kiến sẽ quay lại trước [giờ] | Setting a clear boundary: *"I have plans, but I should be back by 12 PM"* |
| `sometime tomorrow afternoon` | Adverbial | một lúc nào đó vào chiều mai | Approximate time window without making rigid false promises |
| `extenuating circumstance` | Noun Phrase | hoàn cảnh giảm nhẹ / bất khả kháng | Justifying a rare exception: *"Since this is an extenuating circumstance, allow it just this once"* |
| `put a special note` | Collocation | ghi chú đặc biệt vào đơn | Reassuring a customer or stakeholder with specific delivery instructions |
| `held up in traffic` | Collocation | bị giữ chân / kẹt xe | Natural native explanation for transit delays instead of repeated "stuck in traffic" |

### Topic 2: Payment Architecture & Incident Resolution (Days 4–5)
| Collocation / Expression | POS | Vietnamese Meaning | Natural Workplace Context |
| :--- | :--- | :--- | :--- |
| `receive payments via` | Verb Phrase | nhận thanh toán qua [kênh] | Describing omnichannel flow: *"It is possible to receive payments via card scanners or online gateways"* |
| `mandatory deposit of at least` | Phrase | khoản nạp tối thiểu bắt buộc | Explaining banking requirements and account threshold policies |
| `straightforward process` | Adjective + N | quy trình đơn giản, rõ ràng | Reassuring non-tech partners: *"Integrating the new API is a straightforward process"* |
| `solve vs. resolve` | Verbal Contrast | giải toán/fix bug vs giải quyết xung đột/sự cố | *"We solved the code syntax error and resolved the production incident ticket"* |
| `locked out of [system]` | Phrasal Verb | bị khóa quyền truy cập hệ thống | Explaining access failure with the mandatory preposition `of` |
| `for the fifth month in a row` | Time Pattern | tháng thứ 5 liên tiếp | Metric tracking pattern explaining recurring backlog bottlenecks |
| `if that's what needs to be done` | Pragmatic Marker | nếu đó là điều bắt buộc phải làm | Decisive engineering leadership taking responsibility for hard migrations |
