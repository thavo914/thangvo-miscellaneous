# downstream tables

1. (IPA): /ˌdaʊnˈstriːm ˈteɪ.bəlz/

2. Definition

- Tables that depend on data produced earlier in the pipeline (upstream). They are built from source/staging/intermediate tables and change when upstream data or logic changes.

1. Part of Speech

- Noun phrase

1. Usage & 5 Examples

- We held the release because several downstream tables failed quality checks.
- If we change the schema in the bronze layer, all affected downstream tables must be backfilled.
- The metric layer consumes downstream tables sourced from silver.
- This DAG step materializes two downstream tables partitioned by event_date.
- Dashboards broke when an upstream contract breach propagated to downstream tables.

1. Synonyms & Related Terms

- Synonyms: dependent tables, consumer tables, derived tables, downstream datasets
- Related: upstream tables, source tables, staging/bronze/silver/gold tables, semantic layer, marts
