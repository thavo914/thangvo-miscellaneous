## Section B: Grammar & Communication Patterns (15 minutes)

### B1. Conditional Sentences (5 minutes)
**Instructions:** Complete the conditional sentences using the correct grammar structure.

1. **First Conditional (Real Possibility):**
   - If we implement comprehensive testing, our data quality _____ (improve).
   - If the model _____ (fail) validation, the pipeline will stop automatically.

2. **Second Conditional (Hypothetical):**
   - If we _____ (have) better documentation, analysts would be more self-sufficient.
   - If we implemented data contracts, we _____ (reduce) downstream issues.

3. **Third Conditional (Past Hypothetical):**
   - If we _____ (test) the model properly, we wouldn't have had data quality issues.
   - If we _____ (use) version control, we could have rolled back the changes.

## Section C: Speaking Practice (15 minutes)

### C1. Clear Explanation Practice (5 minutes)
**Instructions:** Choose one topic and explain it clearly to someone who doesn't know much about it.

**Choose from:**
- How to improve team communication
- The benefits of good documentation
- Why testing is important
- How to manage project timelines

**Your explanation should include:**
- What the topic is about
- Why it's important
- How it helps people
- A concrete example

**Record your explanation and assess:**
- [ ] Clear pronunciation and articulation
- [ ] Logical structure and flow
- [ ] Appropriate vocabulary for audience
- [ ] Concrete examples provided

### C2. Problem-Solution Presentation (5 minutes)
**Instructions:** Present a solution to a common workplace problem using the Problem-Solution-Impact structure.

**Scenario:** Your team is struggling with poor communication that's affecting project delivery.

**Your presentation should include:**
- Clear problem statement
- Proposed solution
- Expected positive impact
- Timeline for implementation

**Record your presentation and assess:**
- [ ] Problem clearly defined
- [ ] Solution logically connected to problem
- [ ] Impact described clearly
- [ ] Professional tone maintained

### C3. Persuasive Communication (5 minutes)
**Instructions:** Practice explaining a recommendation to someone who has concerns.

**Scenario:** You're recommending implementing better documentation, but your manager is concerned about the time investment.

**Your response should include:**
- Acknowledge their concern respectfully
- Explain the benefits clearly
- Address the time investment honestly
- Provide a balanced recommendation

**Record your response and assess:**
- [ ] Concern acknowledged respectfully
- [ ] Benefits clearly explained
- [ ] Trade-offs honestly discussed
- [ ] Recommendation justified

- Expected positive outcomes
