# Macro

## Definition
Reusable Jinja code that can be called across multiple models to avoid repetition and maintain consistency in data transformations.

## Example Sentences
- "We created a macro for standard date formatting that's used across all our time-based models."
- "Macros help us maintain consistency and reduce code duplication in our dbt project."
- "The team developed custom macros for common business logic patterns."

## Related Terms
- **Jinja**: Templating engine used in dbt
- **Code reuse**: Avoiding duplication through shared functions
- **Consistency**: Maintaining uniform patterns across models
- **Maintainability**: Ease of updating and modifying code

## Usage Context
- Explaining code organization strategies
- Discussing development best practices
- Code review discussions
- Planning project structure
