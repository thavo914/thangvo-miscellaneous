## Exercise 1: Relative Clauses for Technical Definitions

### Instructions
Complete each sentence using appropriate relative clauses (who/which/that) to define technical concepts clearly.

### Practice Sentences

1. **DAG Definition**
   - A DAG is a workflow definition _____ specifies task execution order.
   - **Answer**: A DAG is a workflow definition **that** specifies task execution order.

2. **Idempotent Tasks**
   - Idempotent tasks are operations _____ produce the same result regardless of retries.
   - **Answer**: Idempotent tasks are operations **that** produce the same result regardless of retries.

3. **Deferrable Operators**
   - Deferrable operators are components _____ can pause execution and free up worker slots.
   - **Answer**: Deferrable operators are components **that** can pause execution and free up worker slots.

4. **SLA Monitoring**
   - SLA monitoring is a system _____ tracks compliance with service level agreements.
   - **Answer**: SLA monitoring is a system **that** tracks compliance with service level agreements.

5. **Dynamic Mapping**
   - Dynamic mapping is a feature _____ generates tasks based on runtime data.
   - **Answer**: Dynamic mapping is a feature **that** generates tasks based on runtime data.

## Exercise 2: Reported Speech for Stakeholder Updates

### Instructions
Convert these direct statements to reported speech using appropriate tense changes.

### Practice Sentences

1. **Direct**: "The team says, 'Data quality has improved significantly.'"
   - **Reported**: The team says that data quality has improved significantly.

2. **Direct**: "She tells me, 'The new retry strategy is working well.'"
   - **Reported**: She tells me that the new retry strategy is working well.

3. **Direct**: "They report, 'Processing time has decreased by 50%.'"
   - **Reported**: They report that processing time has decreased by 50%.

4. **Direct**: "The manager said, 'The project was completed successfully.'"
   - **Reported**: The manager said that the project was completed successfully.

5. **Direct**: "They told me, 'The models had been deployed yesterday.'"
   - **Reported**: They told me that the models had been deployed yesterday.

### Advanced Practice
Convert these questions to reported speech:

1. **Direct**: "She asked, 'Have you implemented comprehensive testing?'"
   - **Reported**: She asked if we had implemented comprehensive testing.

2. **Direct**: "They asked, 'Are the models running successfully?'"
   - **Reported**: They asked whether the models were running successfully.

3. **Direct**: "He asked, 'Can you optimize the processing time?'"
   - **Reported**: He asked if we could optimize the processing time.

## Exercise 3: Advanced Conditionals

### Instructions
Complete each sentence using the appropriate conditional structure.

### Simple Conditionals (B1 Level)

1. **If we implement proper testing, we _____ fewer issues.**
   - **Answer**: If we implement proper testing, we **will have** fewer issues.

2. **If the team documents the models properly, analysts _____ more independent.**
   - **Answer**: If the team documents the models properly, analysts **will be** more independent.

3. **If we choose incremental models, we _____ processing time.**
   - **Answer**: If we choose incremental models, we **will save** processing time.

### Unless and As Long As

1. **Unless we implement proper testing, we _____ data quality issues.**
   - **Answer**: Unless we implement proper testing, we **will have** data quality issues.

2. **As long as we follow best practices, our models _____ reliable.**
   - **Answer**: As long as we follow best practices, our models **will be** reliable.

3. **Unless we optimize our queries, processing time _____.**
   - **Answer**: Unless we optimize our queries, processing time **will increase**.

### Provided That

1. **Provided that we test thoroughly, we _____ deploy with confidence.**
   - **Answer**: Provided that we test thoroughly, we **can** deploy with confidence.

2. **Providing that the data is available, the models _____ run successfully.**
   - **Answer**: Providing that the data is available, the models **will** run successfully.

## Exercise 5: Inversion for Formal Style

### Instructions
Rewrite each sentence using inversion to sound more formal and sophisticated.

### Practice Sentences

1. **Original**: We have never had such reliable data quality before.
   - **Inversion**: Never before have we had such reliable data quality.

2. **Original**: We only saw real improvements when we implemented testing.
   - **Inversion**: Only when we implemented testing did we see real improvements.

3. **Original**: dbt not only transforms data, but it also validates it.
   - **Inversion**: Not only does dbt transform data, but it also validates it.

4. **Original**: We had hardly deployed the models when we noticed the performance improvement.
   - **Inversion**: Hardly had we deployed the models when we noticed the performance improvement.

### Advanced Practice

1. **We have never experienced such efficient orchestration.**
2. **We only achieved scalability when we implemented dynamic mapping.**
3. **The system not only processes data, but it also monitors quality.**
4. **We had barely started the migration when we saw improvements.**

## Exercise 6: Presentation Language

### Instructions
Complete each sentence using appropriate presentation language patterns.

### Introducing Topics

1. **Let me begin by _____ our DAG design principles.**
   - **Answer**: Let me begin by **discussing** our DAG design principles.

2. **I'd like to start with _____ the reliability improvements we've achieved.**
   - **Answer**: I'd like to start with **the** reliability improvements we've achieved.

3. **The first point I want to address is _____ task dependency management.**
   - **Answer**: The first point I want to address is **task dependency management**.

### Transitioning Between Points

1. **Moving on to _____ our optimization efforts...**
   - **Answer**: Moving on to **our** optimization efforts...

2. **Another important aspect is _____ our documentation strategy.**
   - **Answer**: Another important aspect is **our** documentation strategy.

3. **In addition to testing, we've also improved _____.**
   - **Answer**: In addition to testing, we've also improved **monitoring**.

### Concluding Points

1. **To summarize, our testing strategy has improved data quality by 80%.**
   - **Answer**: To summarize, our testing strategy has improved data quality by 80%.

2. **The key takeaway is that comprehensive documentation enables self-service analytics.**
   - **Answer**: The key takeaway is that comprehensive documentation enables self-service analytics.

3. **What this means for us is faster delivery and higher quality.**
   - **Answer**: What this means for us is faster delivery and higher quality.
