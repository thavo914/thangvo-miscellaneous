# DAG (Directed Acyclic Graph)

## 1. IPA
/dæɡ/ (rhymes with "bag")

## 2. Definition
A DAG is a workflow definition that specifies the execution order of tasks in a data pipeline, where tasks are represented as nodes and dependencies as directed edges, with no circular dependencies allowed.

## 3. Part of Speech
**Noun** (countable)
- Singular: DAG
- Plural: DAGs

## 4. Usage & Examples (5 examples)

1. "We need to redesign this DAG to reduce complexity."
2. "The DAG failed because of a circular dependency."
3. "Our team maintains over 50 DAGs in production."
4. "Good DAG design is crucial for maintainability."
5. "DAG execution is monitored in real-time."

## 5. Synonyms & Related Terms

### Synonyms
- **Workflow**: "The workflow definition specifies task order."
- **Pipeline**: "The data pipeline processes information sequentially."
- **Graph**: "The execution graph shows task dependencies."

### Related Terms
- **Task**: Individual unit of work in a DAG
- **Dependency**: Relationship between tasks
- **Orchestration**: Process of managing DAG execution
- **Scheduler**: System that triggers DAG runs
- **Executor**: Component that runs individual tasks

### Technical Variations
- **Dynamic DAG**: DAG generated programmatically
- **Modular DAG**: DAG composed of reusable components
- **SubDAG**: DAG embedded within another DAG
