# cost per query

## 1. IPA
/kɔst pər ˈkwɪri/

## 2. Definition
A metric that measures the average cost of executing a single query, calculated by dividing total compute costs by the number of queries executed.

## 3. Part of Speech
noun phrase

## 4. Usage & Examples
- "Our cost per query decreased by 15% after implementing query optimization."
- "We track cost per query to identify expensive queries that need optimization."
- "The cost per query metric helps us understand the efficiency of our data warehouse."
- "We set a target cost per query of $0.50 for our standard analytical queries."
- "Cost per query analysis revealed that some reports are too expensive to run daily."

## 5. Synonyms & Related Terms
- **query cost**: Alternative term for cost per query
- **execution cost**: The cost of running a specific operation
- **processing cost**: General term for computational expenses
- **cost efficiency**: How cost-effective a process is
