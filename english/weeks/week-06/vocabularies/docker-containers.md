# Docker containers

## 1. IPA
/ˈdɑkər kənˈteɪnərz/

## 2. Definition
Lightweight, portable units that package applications and their dependencies, allowing them to run consistently across different environments.

## 3. Part of Speech
noun phrase

## 4. Usage & Examples
- "Our Airflow and dbt services run in Docker containers on Linux servers."
- "Docker containers make it easy to scale our data processing workloads."
- "We use Docker containers to ensure consistent environments across development and production."
- "The Docker containers are orchestrated by our Linux Docker engine."
- "Container resource allocation affects our compute costs significantly."

## 5. Synonyms & Related Terms
- **containers**: General term for containerized applications
- **containerized services**: Services running in containers
- **Docker images**: The templates used to create containers
- **container orchestration**: Managing multiple containers
