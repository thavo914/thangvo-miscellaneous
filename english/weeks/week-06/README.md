# Week 06 – Data Warehouse & Budget Management (Airflow + dbt + MSSQL)

## Outcomes (by end of week)

- Explain on-premises data warehouse architecture choices and justify cost implications to stakeholders.
- Use 8–10 chunks around Airflow + dbt + MSSQL design, cost optimization, and budget management.
- Present budget proposals and defend cost-benefit analysis for on-premises warehouse decisions.
- Handle objections about warehouse costs and demonstrate ROI for Linux + Docker infrastructure.

## Inputs (choose 1–2)

- Article/talk on on-premises data warehouse cost optimization strategies
- Internal documentation on Airflow + dbt + MSSQL budget allocation and ROI metrics
- Case study on on-premises vs cloud warehouse cost analysis

## Chunk Bank (8–12)

- data warehouse; on-premises infrastructure; Linux servers; Docker containers
- cost optimization; budget allocation; ROI analysis; TCO (total cost of ownership)
- MSSQL storage costs; Docker compute costs; data transfer; licensing fees
- Airflow DAG costs; dbt model execution; resource utilization; cost monitoring
- MSSQL data partitioning; compression; archival; lifecycle management
- dbt model optimization; MSSQL query tuning; performance optimization
- budget approval; cost center; chargeback; showback
- cost per dbt model; cost per Airflow DAG; cost per terabyte; cost efficiency

## Grammar/Pronunciation Focus

- **Grammar**: Present perfect for ongoing cost analysis ("We have been tracking costs...")
- **Grammar**: Conditional sentences for budget scenarios ("If we optimize storage, we could save...")
- **Grammar**: Passive voice for cost reporting ("Costs are allocated across departments...")
- **Grammar**: Comparative structures for cost comparisons ("This approach is 40% more cost-effective...")
- **Grammar**: Business presentation language for budget discussions
- **Pronunciation**: Clear articulation of financial terms and percentages
- **Echoing**: Practice budget and cost-related vocabulary and sentence patterns
