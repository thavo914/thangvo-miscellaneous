# DBT Models

## 1. IPA
/diː biː tiː ˈmɒdəlz/

## 2. Definition
Data models created using DBT (data build tool) that define how raw data should be transformed into clean, structured datasets for analysis. DBT models are written in SQL and follow a modular approach.

## 3. Part of Speech
noun phrase

## 4. Usage & Examples
- "I've created several DBT models for the gaming data transformation."
- "The DBT models follow best practices and are modular in design."
- "I'm currently testing the DBT models to ensure accuracy."
- "I'm on track to complete the DBT models this week."
- "The DBT models handle the complex gaming data patterns."

## 5. Synonyms & Related Terms
- **Data models**: General term for structured data representations
- **SQL models**: Models written in SQL language
- **Transformation models**: Models that transform data
- **Data transformations**: The processes defined by the models
