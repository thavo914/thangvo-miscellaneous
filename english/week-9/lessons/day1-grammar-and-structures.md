## 🔍 1. Grammar Focus (3 Target Rules)

### 1. The Third Conditional (Talking about past regrets/choices)
- **Quote:** *"If we had checked our player data last year before launching the campaign, we wouldn't have wasted so much budget..."*
- **Rule Explanation:** We use the Third Conditional to talk about something in the past that did not happen, and imagine the result. It is great for talking about mistakes, regrets, or choices in your past.
  - **Formula:** `If + [Subject] + had + [Past Participle], [Subject] + wouldn't have + [Past Participle]`
- **Common Pitfall Box:**
  > [!WARNING]
  > **Common Mistake:** Avoid using "would" in the "if" part of the sentence.
  > - *Incorrect:* "If we **would have checked** the data, we wouldn't have made the mistake."
  > - *Correct:* "If we **had checked** the data, we wouldn't have made the mistake."

---

### 2. The Passive Voice (Focusing on the action, not the person)
- **Quote:** *"...the data is updated automatically every night."*
- **Rule Explanation:** We use the passive voice when the action is more important than who did it, or when we don't know who did it. It is very common in work environments to describe daily tasks.
  - **Formula:** `[Object] + is/are + [Past Participle of verb]`
- **Common Pitfall Box:**
  > [!WARNING]
  > **Common Mistake:** Forgetting to use the past participle (ending in -ed or irregular form).
  > - *Incorrect:* "The reports **are send** every morning."
  > - *Correct:* "The reports **are sent** every morning."

---

### 3. The Present Perfect Continuous (Actions starting in the past and continuing now)
- **Quote:** *"We have been working on our new data reports since last month..."*
- **Rule Explanation:** We use this tense to talk about an activity that started in the past and is still going on now, or has just finished. It is perfect for describing your current tasks or projects at work.
  - **Formula:** `[Subject] + have/has + been + [Verb-ing]`
- **Common Pitfall Box:**
  > [!WARNING]
  > **Common Mistake:** Do not use the simple present or present continuous with "since".
  > - *Incorrect:* "I **am working** here since last year."
  > - *Correct:* "I **have been working** here since last year."

## 🧱 2. Sentence Structure Templates (5 Patterns)

### Template 1: Explaining the reason for a decision
- **Communicative Function:** Used to explain why you made a specific choice.
- **Slot-Filling Formula:** `[Subject] + decided to + [Verb] + to + [Verb Phrase]`
- **Examples:**
  1. *Everyday Context:* "I decided to read the user manual to avoid breaking the washing machine."
  2. *Data Engineering / Casino Context:* "We decided to upgrade our database server to fix the latency issue."
  3. *General Workplace Context:* "Our team decided to postpone the meeting to get more feedback."

---

### Template 2: Expressing a strong recommendation or warning
- **Communicative Function:** Used to give clear advice or highlight a key task.
- **Slot-Filling Formula:** `It's really important that + [Subject] + [Verb] + before + [Noun/Verb-ing]`
- **Examples:**
  1. *Everyday Context:* "It's really important that you check the weather before going for a run."
  2. *Data Engineering / Casino Context:* "It's really important that we test the query before running it on the main server."
  3. *General Workplace Context:* "It's really important that you talk to the manager before starting the work."

---

### Template 3: Contrasting two ideas (Concession)
- **Communicative Function:** Used to show that you understand a negative point, but the positive point is still true.
- **Slot-Filling Formula:** `Although + [Clause 1], [Subject] + still need to + [Verb Phrase]`
- **Examples:**
  1. *Everyday Context:* "Although public transport is cheap, we still need to save money for emergency taxi rides."
  2. *Data Engineering / Casino Context:* "Although the dataset is quite small, we still need to check it for missing fields."
  3. *General Workplace Context:* "Although we are very busy this week, we still need to finish the training course."

---

### Template 4: Showing a clear cause-and-effect result
- **Communicative Function:** Used to explain how a simple action leads to a positive result.
- **Slot-Filling Formula:** `By + [Verb-ing] + [Object], [Subject] + can + [Verb Phrase]`
- **Examples:**
  1. *Everyday Context:* "By waking up thirty minutes early, you can enjoy a quiet breakfast."
  2. *Data Engineering / Casino Context:* "By checking the system logs daily, we can find and fix errors quickly."
  3. *General Workplace Context:* "By sharing your notes early, you can save the team a lot of time."

---

### Template 5: Looking forward to future improvements
- **Communicative Function:** Used to describe how a current step will make things easier later.
- **Slot-Filling Formula:** `Once + [Subject] + [Present Simple Verb], we can + [Verb Phrase]`
- **Examples:**
  1. *Everyday Context:* "Once you learn how to cook, you can save a lot of money."
  2. *Data Engineering / Casino Context:* "Once the cloud setup is complete, we can migrate the player databases."
  3. *General Workplace Context:* "Once the manager signs the contract, we can start the new project."

1. "If we would have run the database migration without testing, we would have crashed our staging server."
   - *Your Correction*: ____________________________________________________________________
2. "Recently, our data engineering team is working on a major server upgrade since last Monday."
   - *Your Correction*: ____________________________________________________________________
3. "All server logs is checked automatically every night by our security scripts."
   - *Your Correction*: ____________________________________________________________________

<details>
<summary>🔑 Click to reveal Answer Key & Explanations</summary>

1. **Incorrect**: "If we **would have run**..."
   - **Correct**: "If we **had run** the database migration without testing, we would have crashed our staging server."
   - **Why**: In Third Conditionals, never use "would/would have" in the "if" clause. Use the past perfect (`had + past participle`).
2. **Incorrect**: "...**is working**... since last Monday."
   - **Correct**: "Recently, our data engineering team **has been working** on a major server upgrade since last Monday."
   - **Why**: When describing an action that started in the past and is still ongoing with "since" or "for", you must use the Present Perfect Continuous (`has/have been + verb-ing`).
3. **Incorrect**: "...logs **is** checked..."
   - **Correct**: "All server logs **are** checked automatically every night by our security scripts."
   - **Why**: "Logs" is plural, so the passive voice verb must agree and use "are" instead of "is".
