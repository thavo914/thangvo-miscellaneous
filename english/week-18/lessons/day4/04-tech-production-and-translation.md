## 🔍 Drill 3: Spot the Mistake (Error Correction Drill)

Find and fix the technical grammar and collocation mistakes:
1. *We decided to run a POC for check if the tool is more faster than Spark.*  
   → **Your Correction**: __________________________________________________
2. *Implementing this cache will ease burden for the database server.*  
   → **Your Correction**: __________________________________________________
3. *The old cron job must to be phase out because it fails frequently.*  
   → **Your Correction**: __________________________________________________

<details>
<summary>💡 Click to View Explanations & Corrections</summary>

1. **Correction**: *We decided to run a POC **to check** if the tool is **significantly faster than** Spark (or: **much faster than**).*  
   *Explanation*: Use infinitive of purpose `to check` (not `for check`). "More faster" is a double comparative error; use `faster` with an adverb modifier like `significantly` or `much`.
2. **Correction**: *Implementing this cache will **ease the burden on** the database server.*  
   *Explanation*: The fixed native collocation is `ease the burden on` (takes article `the` and preposition `on`, not `for`).
3. **Correction**: *The old cron job **must be phased out** because it fails frequently.*  
   *Explanation*: Modal verbs (`must, can, should`) are followed directly by the base verb `be` without `to`. The passive past participle must be `phased out`, not `phase out`.
</details>
